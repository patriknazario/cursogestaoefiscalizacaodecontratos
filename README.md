# Portal do Aluno — Gestão e Fiscalização de Contratos com IA

Portal do curso **Gestão e Fiscalização de Contratos com Inteligência Artificial** (CGP — Centro de Capacitação em Gestão Pública), com base na Lei nº 14.133/2021 e no Decreto nº 11.246/2022.

- `index.html` — portal completo, arquivo único e autocontido (logo embutida). Pronto para GitHub Pages ou qualquer hospedagem estática.

Conteúdo: 7 módulos + boas-vindas, biblioteca de estudo (guia, mapa de prazos, síntese, política de IA), prompts por área, ferramentas interativas (gerador de documentos e painel de contratos) e materiais no Google Drive.
